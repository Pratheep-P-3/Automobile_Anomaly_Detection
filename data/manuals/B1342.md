# B1342 - ECU Malfunction (Body Control Module)

## System
Body (Body Control Module)

## Description
An internal fault has been detected within the Body Control Module (BCM), which manages
power windows, central locking, interior lighting, and communicates status to other
modules on the vehicle network. This is a critical control module failure.

## Possible Causes
- Internal BCM hardware failure
- Corrupted BCM software/firmware
- Water intrusion causing corrosion on BCM circuit board
- Voltage spike or short circuit damaging the module (e.g., from a bad ground)

## Diagnostic Steps
1. Verify battery voltage and charging system output, as voltage irregularities can
   cause or mimic module faults.
2. Inspect the BCM connector and surrounding area for signs of water intrusion or corrosion.
3. Attempt a BCM software reflash/reset using manufacturer diagnostic software.
4. If reflash fails, test BCM in isolation (bench test) to confirm hardware failure.

## Recommended Service Actions
- Reflash or reset BCM software first, as this resolves many firmware-related faults.
- Replace the BCM if hardware failure is confirmed, followed by required module
  programming/coding to the vehicle.
- Repair any water intrusion source to prevent recurrence.

## Parts / Tools
Manufacturer diagnostic/programming software, battery/charging system tester, BCM unit.

## Safety Notes
This is a critical fault that can affect multiple vehicle systems simultaneously,
including locking and lighting. Advise the customer this requires immediate attention;
do not delay service.
