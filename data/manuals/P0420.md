# P0420 - Catalyst System Efficiency Below Threshold (Bank 1)

## System
Powertrain (Emissions / Exhaust)

## Description
The downstream oxygen sensor readings indicate the catalytic converter on Bank 1 is not
converting exhaust gases as efficiently as expected, suggesting reduced catalyst efficiency.

## Possible Causes
- Deteriorated or failing catalytic converter
- Upstream oxygen sensor malfunction causing incorrect fuel trim
- Exhaust leaks near the catalytic converter
- Engine misfire (e.g., P0300 family codes) causing unburned fuel to damage the catalyst
- Oil or coolant contamination of the catalyst from an internal engine leak

## Diagnostic Steps
1. Check for any active misfire codes first, as misfires often precede catalyst damage.
2. Inspect upstream and downstream oxygen sensor waveforms and compare switching patterns.
3. Inspect exhaust system for leaks between the engine and catalytic converter.
4. Perform a catalyst efficiency test using a scan tool if supported.

## Recommended Service Actions
- Resolve any underlying misfire or lean condition before replacing the catalytic converter.
- Replace the catalytic converter if efficiency test confirms failure and no upstream issue exists.
- Replace faulty oxygen sensors identified during waveform inspection.
- Repair exhaust leaks near the converter.

## Parts / Tools
Lab scope for O2 sensor waveform analysis, exhaust leak detection smoke tool, OBD-II scan tool.

## Safety Notes
This code alone is not a drivability emergency, but the vehicle may fail emissions testing.
Recommend scheduling service within a normal maintenance window.
