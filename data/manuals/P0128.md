# P0128 - Coolant Thermostat Below Regulating Temperature

## System
Powertrain (Cooling System)

## Description
The engine coolant temperature has not reached the expected regulating temperature within
a specified time after startup, usually indicating the thermostat is stuck open or reading
incorrectly.

## Possible Causes
- Thermostat stuck open
- Faulty engine coolant temperature (ECT) sensor
- Low coolant level
- Wiring issue in the ECT sensor circuit

## Diagnostic Steps
1. Monitor live coolant temperature data during a warm-up drive cycle.
2. Inspect the thermostat operation by checking upper radiator hose temperature change timing.
3. Verify coolant level and condition.
4. Test ECT sensor resistance against the temperature/resistance chart.

## Recommended Service Actions
- Replace the thermostat if it is confirmed stuck open.
- Replace the ECT sensor if readings are inconsistent with actual engine temperature.
- Top off or replace coolant if level or condition is poor.

## Parts / Tools
Infrared thermometer, OBD-II scan tool with live data, ECT sensor multimeter test.

## Safety Notes
Low severity code; does not typically require immediate service, but poor heater
performance in cold climates may be a customer comfort concern. Schedule at next
routine maintenance visit.
